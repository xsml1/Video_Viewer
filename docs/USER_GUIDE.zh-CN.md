# Video Viewer 使用说明

## 工作文件夹与混合工作区

点击“选择工作文件夹”，在右侧浏览目录。双击图像或视频即可添加到当前工作区，最多混合 6 路；双击文件夹进入下一级，点 ↑ 返回上一级，← / → 后退或前进，“刷新”重新读取目录。也可粘贴文件夹路径并回车，或把文件/文件夹拖入窗口。目录浏览只读，不移动、重命名或删除源文件。

不再区分图像/视频模式：图像始终静止，所有参与的视频使用同一播放控制器和公共有效区间，图像不会限制视频长度。仅有图像时播放控件禁用。两类素材均可联动缩放、平移、ROI、原生像素查看、标注与导出。

常见 PNG/JPEG/BMP/GIF/TIFF/WebP/AVIF/HEIC/HEIF、SVG、PSD、TGA、ICO 等格式会按内容尝试读取，另支持 rawpy 能识别的相机 RAW（例如 DNG、CR2/CR3、NEF、ARW）。文件选择器还有“所有文件”入口；格式名称不保证所有编码变种都能读取，失败会显示原因。多页 TIFF、动画 GIF/WebP 只取首页/第一帧。带 ICC 的常见 RGB 图像会转换到 sRGB；未嵌入 ICC 时按 sRGB 预览并标记推定。透明区域按白底合成，高位深和 RAW 使用 RGB8 预览，RAW 会显影；这些预览不等于保留原始位深/透明通道。输入文件只读。每路 RGB 缓冲限 512 MiB，总图像组限 1 GiB。图片模式的“保存各图”会写当前 RGB8 预览 PNG 和来源 JSON，原文件不被覆盖。

## 启动与导入

桌面 `Video Viewer` 快捷方式会用项目虚拟环境运行仓库中的最新源码（脚本 `scripts\run_video_compare.cmd`）；也可以在仓库根目录运行 `& .\.venv\Scripts\python.exe -m video_compare --ffprobe <ffprobe.exe 路径>`。构建版运行发布文件夹中的 `main.exe`；构建版优先使用同目录 `bin\ffprobe.exe`，无需设置 PATH。视频只在本机读取，不修改原件。

若要在另一台 Windows 10/11 x64 机器检查构建版是否完整，解压整个发布文件夹后双击其中的 `verify_clean_windows.cmd`。成功时窗口显示 `CLEAN_WINDOWS_SELF_TEST_OK` 和临时结果目录；失败时请保留窗口输出。自检只使用临时生成的视频和图像，不读取您的素材。

在文件夹浏览器中双击素材添加，或将文件拖入窗口。左键把一个画面拖到另一个画面上，看到交换提示后松开即可对调；帧身份、基准视频和视图随素材保留，不重新解码。右键画面可从工作区移除或替换为同类文件，源文件不删除；替换成功才生效，失败保留原路。长片取得真实首帧后即可预览并播放已索引区间；播放到索引前沿会等待下一批真实帧，超出覆盖区的定位保留请求，待索引追上后执行。

## 窗口布局

- **顶部工具栏（一行）**：选择工作文件夹、同步方式、基准视频、查看模式、画面排列、适应画面、框选 ROI、视图联动、全屏、保存视图、保存原帧、导出对比图，以及“设置”和“侧栏”开关。
- **视频窗口**：中间是唯一的对比画布。每路画面的**左上角显示视频文件名**，**右下角显示帧号、PTS 与提醒**（如色彩推定）；文字带半透明底衬，默认绿色，颜色可在设置里改成任意颜色或“跟随色系”。
- **播放条（视频窗口下方）**：进度条、播放/暂停、前后步进、步进量（帧/秒）、速度、I/O 循环边界、区间循环、时间与帧号定位输入，以及底部状态文字与循环状态。
- **右侧文件夹浏览器**：当前路径、目录与图像/视频文件、导航按钮。原文件列表操作栏、Offset 和 Marker 面板已移除。拖动左侧分隔条调整宽度；点 `»` 隐藏，点顶部“侧栏”恢复。

## 同步与定位

“按时间同步”使用各路视频实际 PTS，并以所有参与路的公共有效区间播放。不同帧率的视频可能在同一显示事件中分别保持各自最近的有效帧，这不表示错帧。“按帧号同步”按解码后的显示顺序对齐序号，不用平均 FPS 推算 VFR 帧号。

界面帧号从 1 开始；输入框中的“帧 1”就是源视频第一张显示帧。时间码格式为 `HH:MM:SS.mmm`。可用进度条、时间码或基准帧号定位；快速连续步进会累计目标，不会反复从尚未更新的旧画面起算。

基准下拉框只列视频，静态图像不参与时间映射。切换基准时已显示内容会尽量保持。窗口对调只改变排列位置，不改变同步含义。

播放速度可选 0.25–4×。I/O 按已显示的完整帧组设置循环起点/终点，循环区间为含起点、不含终点。严格同步模式不会为了追速度让各路独立跳帧；机器负载较高时实际速度可能低于设定值。

## 查看与截图

点顶部“全屏”或按 F11，将工作区画布铺满当前屏幕，顶部工具栏、文件夹和播放条暂时隐藏。空格播放/暂停视频，左/右键按当前步进设置后退/前进，Ctrl+滚轮缩放。按 Esc 或点右上角 × 退出，恢复原窗口大小/最大化状态、侧栏和布局。图像仍保持静止，进入/退出全屏不更换画布或重新启动解码。全屏中 Esc 优先退出全屏，ROI 开关与先前单路最大化状态保留。

“同区域查看”以归一化内容坐标联动缩放/平移/ROI，不把标题和黑边算作视频区域。“原生像素 100%”让一个源采样像素对应一个 framebuffer 物理像素，忽略 SAR。Ctrl+滚轮调整倍率，同格左键拖动或中键拖动平移；左键跨格拖放交换画面。打开“框选 ROI”后拖出区域用于框选，标注编辑时用于绘画，不交换位置。“适应画面”恢复视图。双击某一路单路查看，双击或 Esc 返回网格；隐藏视频仍参与同步。

画面排列由导入视频自己决定，可在工具条“排列”里切换“自动（按画面比例）/网格排列/横向排列/竖向排列”；竖屏视频会自动并排紧凑显示，不会在中间留出大片空白。自动模式下多增加一行必须能明显放大画面才会采用，因此常规情况下两路仍然并排。

“导出对比图…”把当前窗口里看到的画面区域导出成一张对比图：可选“与窗口一致/横向排列/竖向排列/网格排列”，可选 PNG 或 JPEG（JPEG 可调质量）。导出图会**连画面左上角的文件名、右下角的帧号/PTS/提醒一起保存**，但不含按钮、工具栏、侧栏等界面元素，也**不再生成 JSON 文件**；成功或失败都会弹窗提示并显示完整保存路径（成功提示里带组 ID）。选择的文件路径允许覆盖（Windows 保存对话框会先确认）；PQ、HLG 和 BT.2020 的已支持预览可导出，提醒注明 SDR 色调映射；未支持的色彩编码明确提示。

需要边看边标时，在导出对话框勾选**“导出前先编辑标注”**：选好路径后进入标注模式，在任意画面上拖拽可画**矩形、圆形/椭圆、箭头、直线**；选择**“自由画笔”**后按住鼠标左键移动，可沿指针轨迹绘画。线条颜色有红橙黄绿青蓝紫白黑九种。编辑工具条的“标注联动到全部画面”默认勾选，此时新标注同步显示在所有参与画面；取消勾选后，新画的框选、自由画笔及其他图形只落在起笔的那一路图像或视频，导出图也如此。中途切换只影响之后的新笔画。顶部“视图联动”只控制缩放、平移和 ROI，不决定标注范围。标注锚定在源画面位置，编辑中缩放或平移后仍跟随画面内容。工具条可撤销上一笔、从列表选择后删除单个标注，或删除全部。点击“完成并导出”且保存成功后，标注从画面消失；保存失败时保留以便重试；点击“取消编辑”会立即清除本次标注，且不会写出文件。

“保存视图”保存当前画布（含文件名、帧号与提醒标注）；“保存原帧”保存各路 RGB8 预览，并生成记录组 ID、PTS、帧号及来源的 JSON。混合组包含所有图像/视频，图像标明静态且没有视频帧号。截图来自已提交的完整帧组，默认不覆盖同名文件。

## 常用快捷键

空格在主窗口任何控件有焦点时都只控制视频播放/暂停，不按下其他按钮、不添加文件，也不在输入框写入空格；按住时只切换一次，弹出的模态对话框按自身规则处理。Ctrl+O 选择工作文件夹。画布有焦点时，左/右方向键步进、Home/End 定位公共区间两端、F 适应、I/O 设置循环边界、Esc 取消拖拽/ROI 或返回网格。文字输入框中的方向键继续用于编辑文字。

## 主题与语言

顶部工具栏右侧的“设置”分为“主题”和“语言”。“主题”保留原有的明暗模式、整体色彩与四个颜色角色。

“语言”可选择简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español。下拉选项始终使用该语言自己的名称，切换后界面立即更新，重启仍保留选择。

- **整体色彩**只决定色系风格：清爽极简、莫兰迪、奶油风、复古、赛博朋克、马卡龙；明暗模式（跟随系统/浅色/深色）决定用该色系的浅色还是深色版本。
- 选择**跟随系统**时，应用会在 Qt 收到系统明暗变化通知后自动刷新界面颜色；手动指定浅色或深色后不会随系统切换。
- **四个颜色角色**分别选色：**工作区**（视频窗口背景、画面框）、**功能区**（工具栏、播放条、侧栏与控件）、**强调色**（选中状态、进度条、画布高亮）、**视频信息**（画面左上角文件名与右下角帧信息的文字颜色，默认绿色）。先点上面的角色按钮，再点色块即可。
- **色板**与 PPT/Visio 的填充颜色一致：上面 6 行是所选色系的主题色及其由浅到深的 5 档深浅（右侧为原色），最下面一行是 15 个标准色；点任意色块即把该颜色用于当前角色，右侧显示当前颜色与十六进制值。“跟随色系”让该角色使用色系主色。
- 修改立即生效并写入 `settings.toml`；色系与强调色只影响界面与画布装饰，不会改变视频像素、播放位置或截图内容。

## 显示限制

当前统一转换为 RGB8 SDR 预览；源为 10-bit 时会标注“源 10-bit，当前 8-bit 预览”。色彩元信息缺失时会标出推定。PQ/HLG 转成带提醒的 SDR 色调映射预览，BT.2020/P3 SDR 转至 BT.709；源峰值缺失时显示推定值。截图保存已显示的 RGB8 像素，原帧 JSON 同时保留源色彩信息。它们不能用于评价原生 HDR 屏幕绝对亮度；非兼容 Dolby Vision 与 BT.2020 CL 明确拒绝。16 位整数图像按高 8 位预览并提示，浮点/HDR 静态图像仍未支持。详见 `docs/FORMAT_SUPPORT.zh-CN.md`。视频播放无音频，也不提供转码或视频导出。完整已知问题与验收状态见仓库的 `KNOWN_ISSUES.md`、`reports/ACCEPTANCE.md`。
